## Tài liệu

### A. Từ vựng *Personality & Emotions* (30 từ khởi đầu)

| Từ | Nghĩa | Từ | Nghĩa |
|---|---|---|---|
| ambitious | tham vọng, hoài bão | generous | rộng lượng ↔ mean, selfish |
| confident | tự tin (confidence) | modest | khiêm tốn ↔ arrogant |
| determined | quyết tâm | reliable | đáng tin cậy |
| optimistic | lạc quan ↔ pessimistic | sensible | hợp lý ↔ **sensitive** (nhạy cảm) |
| patient | kiên nhẫn ↔ impatient | considerate | chu đáo (consider) |
| hard-working | chăm chỉ | easy-going | dễ tính |
| sociable | hòa đồng | shy | nhút nhát |
| honest | trung thực ↔ dishonest | stubborn | bướng bỉnh |
| curious | tò mò (curiosity) | creative | sáng tạo |
| frustrated | bực bội, nản | disappointed **with / in** | thất vọng |
| embarrassed | ngượng | delighted | rất vui |
| anxious **about** | lo lắng | relieved | nhẹ nhõm |
| jealous **of** | ghen tị | grateful **to sb for sth** | biết ơn |
| proud **of** | tự hào | ashamed **of** | xấu hổ |
| lose your temper | nổi nóng | keep calm | giữ bình tĩnh |

> **Tính từ -ed / -ing:** *-ed* chỉ cảm xúc của người (*I'm bored*), *-ing* chỉ tính chất gây ra cảm xúc (*The film is boring*).

### B. Câu điều kiện nâng cao

| Cấu trúc | Ví dụ |
|---|---|
| **Hỗn hợp 3 + 2** (quá khứ → hiện tại): If + QKHT, would + V (now) | If I **had taken** the medicine, I **would feel** better **now**. |
| **Hỗn hợp 2 + 3** (tính chất hiện tại → quá khứ): If + QKĐ, would have V3 | If he **were** more careful, he **wouldn't have made** that mistake. |
| **Đảo ngữ loại 1:** Should + S + V | **Should** you need help, call me. |
| **Đảo ngữ loại 2:** Were + S + to V / Were + S + ... | **Were** I rich, I would travel. · **Were** he **to** come, ... |
| **Đảo ngữ loại 3:** Had + S + V3 | **Had** I known, I would have told you. |
| **Đảo ngữ phủ định:** đặt *not* sau chủ ngữ | **Had** she **not** helped me, I would have failed. |
| **But for / Without** + N = If it weren't for / If it hadn't been for | **But for** your help, I would have failed. |
| **Provided (that) / As long as / On condition that** = chỉ khi | You can go out **as long as** you finish your homework. |
| **Otherwise** = nếu không thì | Hurry up, **otherwise** you'll be late. |
| **Suppose / Supposing (that)** = giả sử | **Supposing** you won the lottery, what would you do? |

### C. Giải bài toán bằng cách lập phương trình bậc hai

1. **Đặt ẩn**, ghi rõ đơn vị và **điều kiện** (x > 0, x nguyên...).
2. Biểu diễn các đại lượng chưa biết theo ẩn (lập bảng nếu bài nhiều đại lượng).
3. **Lập phương trình**, giải.
4. **Đối chiếu điều kiện**, loại nghiệm không phù hợp (thường là nghiệm âm).
5. **Kết luận** bằng câu trả lời đầy đủ.

Dạng thường gặp: chuyển động (v = s/t; xuôi dòng = v + v_nước), năng suất (làm chung: 1/x + 1/y = 1/t), hình học (diện tích, chu vi), giá tiền – số lượng.
