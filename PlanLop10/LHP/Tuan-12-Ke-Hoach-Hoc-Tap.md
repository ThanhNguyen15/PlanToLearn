### D. Hệ thức lượng trong tam giác vuông

Tam giác ABC vuông tại A, đường cao AH, cạnh huyền BC = a, AC = b, AB = c, BH = c', CH = b', AH = h.

| Hệ thức | |
|---|---|
| b² = a·b' ; c² = a·c' | |
| h² = b'·c' | |
| a·h = b·c | |
| 1/h² = 1/b² + 1/c² | |
| a² = b² + c² (Py-ta-go) | |

**Tỉ số lượng giác góc nhọn α:** sin α = đối/huyền · cos α = kề/huyền · tan α = đối/kề · cot α = kề/đối.
**Hai góc phụ nhau:** sin α = cos(90° − α), tan α = cot(90° − α).
